# Programming Foundations Lab

Catálogo organizado de exercícios práticos de JavaScript e Python desenvolvidos durante a formação.

## Objetivo

Este repositório centraliza o acesso aos estudos de fundamentos de programação. Os exemplos estão agrupados por tema para facilitar a leitura, enquanto os repositórios originais continuam preservados como histórico.

## Navegação

- [JavaScript](javascript/README.md): variáveis, condicionais, laços, vetores, funções e desafios.
- [Python](python/README.md): fundamentos, estruturas de dados, JSON, bibliotecas e automação.

## Para recrutadores

Estes materiais demonstram a construção de base em lógica e programação. Para projetos de Dados, BI e IA com escopo de negócio, consulte os repositórios de portfólio destacados no perfil.

## Organização e privacidade

O catálogo não contém credenciais, dados pessoais ou informações corporativas. Exemplos são educacionais e não devem conter chaves, tokens ou dados de terceiros.
